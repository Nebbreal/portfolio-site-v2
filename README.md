# Portfolio V2
This repository contains the source code for the second version of my portfolio site. 
The site is built on React + Tailwind.

The source code can be found in the ``src`` folder and most assets are stored in the ``public/assets`` folder.

# How to run
Visit https://www.dvanlaarhoven.com/.

**or**
## Requirements
- Node 26.8.1
## Running the application
1. Run ``npm i`` to install dependencies.
2. Run ``npm run dev`` to run a development build.

**or** 

2. Run ``npm run build`` to build the site.
3. Run ``npm run preview`` to run the site.
